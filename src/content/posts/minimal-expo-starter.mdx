[Minimal Expo Starter](https://github.com/qiyangdev/minimal-expo-starter) is an open-source template I created for building iOS and Android apps with Expo.

It comes with Expo Router, native tabs, and separate navigation stacks for Home and Settings. It also uses `@expo/ui` components based on SwiftUI and Jetpack Compose. TypeScript, typed routes, React Compiler, and ESLint are ready to use.

The template gives you a simple place to start. Replace the example screens and app details, then add the features you need.

The `main` branch stays simple. Other branches add features you can try:

- [`notifications`](https://github.com/qiyangdev/minimal-expo-starter/tree/notifications) adds iOS push notifications and a test script.
- [`with-ai`](https://github.com/qiyangdev/minimal-expo-starter/tree/with-ai) shows how to generate text on a device.
- [`iphone-duo-demo`](https://github.com/qiyangdev/minimal-expo-starter/tree/iphone-duo-demo) shows a split layout using ArrangementView on supported iOS versions.

To get started, clone the [repository](https://github.com/qiyangdev/minimal-expo-starter), install dependencies with `bun install`, and run `bun start`.
